# Kaggle Open Problems - Multimodal Single-Cell Integration 数据整合总结（含文件名释义）
## 一、核心数据文件清单及含义
竞赛数据以 **HDF5（.h5格式，存储多模态表达矩阵）** 和 **CSV（存储元数据/辅助信息）** 为主，各文件按“数据类型（模态）+ 训练/测试用途 + 核心内容”命名，具体含义如下：

| 文件名 | 数据类型 | 核心内容 | 用途 |
| ---- | ---- | ---- | ---- |
| `train_multi_inputs.h5` | Multiome模态（DNA+RNA） | 训练集ATAC-seq数据：染色质可及性（DNA层面），经TF-IDF转换（`log(TF)*log(IDF)`），行=细胞，列=基因组坐标（基于GRCh38参考基因组） | 作为Multiome模态的**输入特征**，用于训练“DNA→RNA”预测模型 |
| `test_multi_inputs.h5` | Multiome模态（DNA+RNA） | 测试集ATAC-seq数据：结构与训练集一致，仅包含待预测的细胞染色质可及性数据 | 作为Multiome模态的**测试输入**，需基于此预测对应细胞的RNA表达 |
| `train_multi_targets.h5` | Multiome模态（DNA+RNA） | 训练集Multiome的RNA表达数据：与`train_multi_inputs.h5`的细胞一一对应，经文库大小归一化和log1p转换 | 作为Multiome模态的**训练标签**，用于拟合“DNA→RNA”预测关系 |
| `train_cite_inputs.h5` | CITE-seq模态（RNA+蛋白） | 训练集CITE-seq的RNA表达数据：行=细胞，列=基因（命名格式为`{gene_name}_{gene_ensemble-ids}`），经文库大小归一化和log1p转换 | 作为CITE-seq模态的**输入特征**，用于训练“RNA→蛋白”预测模型 |
| `test_cite_inputs.h5`（含细分文件如`test_cite_inputs_day_2_donor_27678.h5`） | CITE-seq模态（RNA+蛋白） | 测试集CITE-seq的RNA表达数据：细分文件按“采集时间（day）+供体（donor）”划分（如`day_2_donor_27678`表示供体27678在第2天的样本），结构与训练集一致 | 作为CITE-seq模态的**测试输入**，需基于此预测对应细胞的蛋白表达 |
| `train_cite_targets.h5` | CITE-seq模态（RNA+蛋白） | 训练集CITE-seq的蛋白表达数据：与`train_cite_inputs.h5`的细胞一一对应，经DSB归一化（专为蛋白数据设计的归一化方法） | 作为CITE-seq模态的**训练标签**，用于拟合“RNA→蛋白”预测关系 |
| `metadata.csv` | 全模态通用元数据 | 所有细胞的注释信息，关键字段包括：<br>- `cell_id`：细胞唯一标识（用于关联各模态数据）<br>- `donor`：供体ID（共4个健康供体，如27678、13176等）<br>- `day`：采集时间（0-10天，不同模态采集时间范围不同）<br>- `technology`：测序技术（`citeseq`/`multiome`）<br>- `cell_type`：细胞类型（如HSC造血干细胞、EryP红细胞祖细胞等，或`hidden`未标注类型） | 用于**关联多模态数据**（通过`cell_id`对齐不同模态的同一细胞），以及添加细胞背景注释（供体、时间、类型等） |
| `evaluation_ids.csv` | 测试集评估辅助文件 | 测试集待评估标签的索引映射：包含`cell_id`（细胞标识）、`gene_id`（特征标识）与`row_id`（提交文件所需的行ID）的对应关系 | 明确测试集中需提交预测结果的“细胞-特征”对，确保提交格式符合评分要求 |
| `sample_submission.csv` | 提交格式示例文件 | 空白预测结果模板，包含`row_id`（与`evaluation_ids.csv`对应）和`target`（待填写的预测值）两列 | 提供正确的提交文件格式参考，避免因格式错误导致评分失败 |


## 二、多模态数据整合到h5ad的核心逻辑
需基于 **AnnData数据结构**（`scanpy`库标准格式），通过“细胞ID对齐+模态区分+元数据关联”实现整合，核心步骤如下：

### 1. 数据读取与基础对齐（关键：统一`cell_id`）
- **表达矩阵读取**：用`h5py`读取各`.h5`文件，提取核心数据（如`block0_values`=表达矩阵、`axis1`=细胞ID、`axis0`=特征名），确保所有模态的`cell_id`完全一致（通过`metadata.csv`的`cell_id`作为“统一钥匙”）。
- **无效数据过滤**：删除元数据中无对应注释的细胞（如`metadata.csv`中不存在的`cell_id`），避免数据冗余。

### 2. 模态区分与特征标注（关键：`var`表加`feature_type`）
在AnnData的`var`（特征注释表）中添加`feature_type`字段，明确区分不同模态的特征，避免混淆：
- Multiome模态：`feature_type="atac_peak"`（ATAC-seq特征，DNA层面）、`feature_type="multi_rna"`（Multiome的RNA特征）；
- CITE-seq模态：`feature_type="cite_rna"`（CITE-seq的RNA特征）、`feature_type="protein"`（CITE-seq的蛋白特征）。

### 3. 多模态数据存储（关键：用`layers`分存不同模态）
AnnData的`X`（核心矩阵）默认存储“主要输入特征”（如CITE-seq的RNA表达、Multiome的ATAC-seq数据），其他模态数据通过`layers`（分层存储）区分：
- `adata.layers["protein_expression"]`：存储CITE-seq的蛋白表达数据（训练集`train_cite_targets.h5`）；
- `adata.layers["multi_rna_expression"]`：存储Multiome的RNA表达数据（训练集`train_multi_targets.h5`）；
- `adata.obs`：存储`metadata.csv`的所有注释字段（`donor`/`day`/`cell_type`/`technology`），实现“细胞-背景-多模态特征”的关联。

### 4. 辅助信息补充（`uns`表存元数据）
在AnnData的`uns`（非结构化注释表）中添加数据来源、归一化方法等信息，方便后续追溯：
- `adata.uns["data_sources"]`：记录各模态数据的原始文件名（如`train_cite_inputs.h5`）；
- `adata.uns["normalization"]`：记录各模态的归一化方式（如RNA用`log1p`、蛋白用`DSB`）。


## 三、整合后h5ad文件的核心价值
整合后的h5ad文件可直接用于`scanpy`/`scvi-tools`等单细胞分析工具，实现：
1. **跨模态联动分析**：如通过`cell_id`查看同一细胞在DNA（ATAC）、RNA、蛋白三个层面的表达特征；
2. **模型训练便捷性**：无需反复读取多个`.h5`/`csv`文件，直接从`adata.X`（输入）、`adata.layers`（标签）调用数据；
3. **下游可视化**：结合`adata.obs`的`cell_type`/`donor`等注释，快速绘制跨模态细胞聚类图、特征相关性热图等。


## 四、整合注意事项
1. **数据量适配**：部分`.h5`文件（如`train_cite_inputs.h5`）体积较大（可能达数GB），需分块读取（用`h5py`的切片功能），避免内存溢出；
2. **测试集特殊处理**：测试集无`targets`数据（如`test_cite_inputs.h5`无对应蛋白数据），整合时仅需存储输入特征和元数据，`layers`中不添加标签字段；
3. **特征名去重**：若不同模态存在同名特征（如不同模态的RNA基因名重复），需在`var`表中添加模态前缀（如`cite_rna_XXX`/`multi_rna_XXX`），避免索引冲突。

### 一、明确三类核心文件的具体构成
整合时需要根据“训练集/测试集”场景，选择对应细分文件，具体对应关系如下：

| 数据类别 | 训练集需包含的细分文件 | 测试集需包含的细分文件 | 核心作用 |
|----------|------------------------|------------------------|----------|
| **Multiome模态文件** | `train_multi_inputs.h5`（ATAC-seq DNA数据）、`train_multi_targets.h5`（Multiome的RNA数据） | `test_multi_inputs.h5`（仅ATAC-seq DNA数据，无targets） | 提供“DNA- RNA”模态的表达数据，训练集含输入+标签，测试集仅含输入 |
| **CITE-seq模态文件** | `train_cite_inputs.h5`（CITE-seq的RNA数据）、`train_cite_targets.h5`（CITE-seq的蛋白数据） | `test_cite_inputs.h5`（或细分文件如`test_cite_inputs_day_2_donor_27678.h5`，仅RNA数据） | 提供“RNA-蛋白”模态的表达数据，训练集含输入+标签，测试集仅含输入 |
| **metadata文件** | `metadata.csv`（全量细胞注释） | `metadata.csv`（全量细胞注释） | 用`cell_id`关联Multiome和CITE-seq的细胞，补充`donor`/`cell_type`等背景信息 |


### 二、整合的核心逻辑：以“cell_id”为纽带串联三类文件
三类文件并非独立使用，而是通过`metadata.csv`中的`cell_id`实现“跨模态细胞对齐”，具体逻辑如下：
1. **第一步：用metadata.csv确定“统一细胞列表”**  
   先读取`metadata.csv`，提取所有`cell_id`，并按`technology`字段（`multiome`/`citeseq`）区分细胞所属模态，避免后续整合时混入无关细胞。
2. **第二步：分别读取Multiome和CITE-seq的表达数据**  
   - 对Multiome文件：提取`axis1`（细胞ID）和`block0_values`（表达矩阵），仅保留`metadata.csv`中存在的`cell_id`对应的行数据。
   - 对CITE-seq文件：同理，按`metadata.csv`的`cell_id`过滤表达矩阵，确保与Multiome的细胞范围一致（或仅保留目标模态细胞，如仅整合CITE-seq细胞）。
3. **第三步：将三类数据嵌入AnnData结构**  
   - `adata.obs`：存入`metadata.csv`的所有注释（`donor`/`day`/`cell_type`/`technology`）。
   - `adata.X`：默认存“核心输入特征”（如CITE-seq的RNA数据，或Multiome的ATAC数据）。
   - `adata.layers`：存其他模态数据（如Multiome的RNA、CITE-seq的蛋白，仅训练集有）。
   - `adata.var`：标注特征所属模态（如`feature_type="atac_peak"`/`"protein"`）。


### 三、特殊场景：仅整合单一模态时的文件简化
如果不需要同时整合两种模态（如仅处理CITE-seq），则可简化文件范围：
- 仅整合CITE-seq（训练集）：只需`train_cite_inputs.h5`、`train_cite_targets.h5`、`metadata.csv`。
- 仅整合Multiome（测试集）：只需`test_multi_inputs.h5`、`metadata.csv`。

但如果目标是“完整多模态整合”（同时包含DNA、RNA、蛋白数据），则必须同时用到上述三类文件的细分文件。

#### 核心整合逻辑
1. **统一细胞ID**：确保所有数据（基因表达、蛋白表达、元数据）的 `cell_id` 完全对齐。
2. **区分特征模态**：在 `var` 中添加 `feature_type` 列，标记基因（`gene`）/蛋白（`ADT`），避免不同模态特征混淆。
3. **整合目标变量**：训练集将蛋白表达作为 `layers["protein_expression"]` 存储（方便后续模型训练调用）。
4. **补充元数据**：将 `donor`/`day`/`cell_type` 等注释存入 `obs`，实现“细胞-注释-多模态表达”的关联。


#### 完整整合代码
```python
import scanpy as sc
import h5py
import pandas as pd
import numpy as np

def integrate_multimodal_to_h5ad(
    cite_inputs_path,    # CITE-seq基因表达h5路径（如train_cite_inputs.h5）
    cite_targets_path,   # CITE-seq蛋白表达h5路径（如train_cite_targets.h5，训练集用）
    metadata_path,       # 元数据csv路径（如metadata.csv）
    output_h5ad_path,    # 输出h5ad路径
    is_train=True        # 是否为训练集（测试集无targets，设为False）
):
    # -------------------------- 1. 读取CITE-seq基因表达数据 --------------------------
    with h5py.File(cite_inputs_path, "r") as f:
        cite_group = f["train_cite_inputs"] if "train" in cite_inputs_path else f["test_cite_inputs"]
        # 提取基因表达核心数据
        gene_expr = cite_group["block0_values"][:]  # 基因表达矩阵（细胞数×基因数）
        cell_ids = cite_group["axis1"][:].astype(str)  # 细胞ID（所有数据的统一索引）
        gene_names = cite_group["axis0"][:].astype(str)  # 基因名称

    # 构建基因特征注释（标记模态类型）
    var_gene = pd.DataFrame(index=gene_names)
    var_gene["feature_type"] = "gene"  # 标记为基因模态


    # -------------------------- 2. 读取CITE-seq蛋白表达数据（训练集专属） --------------------------
    if is_train and cite_targets_path is not None:
        with h5py.File(cite_targets_path, "r") as f:
            protein_group = f["train_cite_targets"]
            # 提取蛋白表达核心数据
            protein_expr = protein_group["block0_values"][:]  # 蛋白表达矩阵（细胞数×蛋白数）
            protein_names = protein_group["axis0"][:].astype(str)  # 蛋白名称

        # 构建蛋白特征注释（标记模态类型）
        var_protein = pd.DataFrame(index=protein_names)
        var_protein["feature_type"] = "protein"  # 标记为蛋白模态

        # 合并基因+蛋白的特征注释（var）
        var_combined = pd.concat([var_gene, var_protein], axis=0)
        # 合并基因+蛋白的表达矩阵（X存基因，layers存蛋白；或X存合并矩阵，根据需求选）
        # 这里选择“X存基因表达，layers["protein"]存蛋白表达”（更符合scanpy习惯）
        layers_combined = {"protein_expression": protein_expr}
    else:
        # 测试集无蛋白目标，仅保留基因数据
        var_combined = var_gene
        layers_combined = None


    # -------------------------- 3. 读取并匹配元数据（obs） --------------------------
    metadata = pd.read_csv(metadata_path)
    # 关键：用细胞ID对齐元数据（确保元数据cell_id列与cell_ids一致）
    metadata = metadata.set_index("cell_id").reindex(cell_ids)
    # 过滤无效细胞（若元数据中无对应细胞，删除该细胞的所有数据）
    valid_cells = ~metadata.index.isna()
    cell_ids_valid = cell_ids[valid_cells]
    gene_expr_valid = gene_expr[valid_cells, :]
    metadata_valid = metadata[valid_cells]
    # 若有蛋白数据，同步过滤
    if is_train:
        protein_expr_valid = protein_expr[valid_cells, :]
        layers_combined["protein_expression"] = protein_expr_valid


    # -------------------------- 4. 构建最终的AnnData对象 --------------------------
    adata = sc.AnnData(
        X=gene_expr_valid,  # 核心表达矩阵（默认存基因表达）
        obs=metadata_valid,  # 细胞元数据（donor/day/cell_type等）
        var=var_combined,    # 特征元数据（含模态类型标记）
        layers=layers_combined  # 额外模态数据（蛋白表达，训练集专属）
    )

    # （可选）添加文件来源注释（存入uns，方便后续追溯）
    adata.uns["data_source"] = {
        "cite_inputs": cite_inputs_path,
        "cite_targets": cite_targets_path if is_train else "test_set_no_target",
        "metadata": metadata_path,
        "is_train_set": is_train
    }


    # -------------------------- 5. 保存为h5ad文件 --------------------------
    adata.write_h5ad(output_h5ad_path)
    print(f"整合完成！h5ad文件保存至：{output_h5ad_path}")
    print(f"整合后数据信息：")
    print(f"- 细胞数：{adata.n_obs}，特征数：{adata.n_vars}")
    print(f"- 细胞注释列：{list(adata.obs.columns)}")
    print(f"- 特征模态分布：{adata.var['feature_type'].value_counts().to_dict()}")
    print(f"- 额外模态层：{list(adata.layers.keys()) if layers_combined else '无'}")


# -------------------------- 调用函数（需替换为你的实际路径） --------------------------
```

### 三、后续调整方向（根据你补充的字段）
1. **若有 ATAC-seq 数据**：
